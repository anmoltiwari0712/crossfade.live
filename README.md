# crossfade.live

Product launch website for **CrossFade for UTube Music**.

- **Extension Repository:** `anmoltiwari0712/CrossFade`
- **Chrome Web Store:** https://chromewebstore.google.com/detail/efiacbdpmdpecdbkjfpoblkicbnemgno
- **Developer:** [Anmol Tiwari](https://github.com/anmoltiwari0712) (`oanmoltiwari7@gmail.com`)

## Features
- Interactive **Equal Power vs. Linear** crossfade curve visualizer + live Web Audio API synth audition
- **"Hear from our audience"** auto infinite-scroll carousel
- Moderated comment composer with abusive-language, obfuscation, XSS, and spam sanity filtering
- Public `#privacy` promise section
